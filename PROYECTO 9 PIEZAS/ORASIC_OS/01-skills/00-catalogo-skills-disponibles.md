# Catálogo inicial de skills ya disponibles

Esto es un hallazgo importante para tu operación: **una parte grande de la "pieza 6" ya existe**, instalada como skills/plugins en tu entorno de Cowork. Tu trabajo no es construir todo desde cero — es curar cuáles usas, probarlos con casos reales, y documentarlos con la plantilla de `00-como-crear-un-skill.md` una vez confirmes que funcionan para tu forma de trabajar.

## Skills transversales (útiles en casi cualquier proyecto de cliente)

| Skill | Para qué sirve | Caso ORASIC típico |
|---|---|---|
| `docx` | Crear/editar documentos Word | Contratos, propuestas, documentación técnica de entrega |
| `xlsx` | Crear/editar hojas de cálculo | Reportes financieros, cotizaciones, seguimiento de leads |
| `pptx` | Crear/editar presentaciones | Propuestas comerciales, entregables ejecutivos para el cliente |
| `pdf` | Manipular PDFs (unir, dividir, OCR, formularios) | Empaquetar el entregable final "Sello ORASIC" |
| `canvas-design` | Piezas visuales (posters, diseño) | Assets de marca para el cliente |
| `mcp-builder` | Construir un MCP nuevo desde cero | Cuando un cliente necesita una integración que no existe todavía (ej. una herramienta LATAM sin conector) |
| `web-artifacts-builder` | Artefactos web interactivos complejos | Dashboards o demos interactivas para mostrar al cliente |
| `skill-creator` | Crear/optimizar skills nuevos | Meta-herramienta: úsalo para construir los próximos skills de este catálogo |

## Paquetes verticales ya instalados (skills de negocio, no solo de formato)

Esto es lo más valioso para tu diferenciación: son paquetes completos de skills orientados a un rol de negocio, ya construidos.

| Paquete | Skills incluidos (ejemplos) | Vertical de cliente donde aplica |
|---|---|---|
| `small-business:*` | cash-flow-snapshot, invoice-chase, month-end-prep, crm-cleanup, margin-analyzer, tax-season-organizer, customer-pulse, lead-triage | PYMEs — el corazón de tu mercado objetivo probable en LATAM |
| `finance:*` | financial-statements, journal-entry, reconciliation, variance-analysis, sox-testing | Clientes con función financiera formal (empresas medianas+) |
| `sales:*` | pipeline-review, forecast, call-prep, account-research, draft-outreach | Clientes con equipo comercial activo |
| `marketing:*` | campaign-plan, content-creation, seo-audit, performance-report, brand-review | Clientes que necesitan operación de marketing |
| `product-management:*` | write-spec, roadmap-update, sprint-planning, metrics-review | Clientes que son en sí mismos empresas de producto/software |

## Regla operativa

1. **No le vendas a un cliente un paquete completo "porque existe".** Diagnostica primero (`05-workflows/`) y activa solo lo que su workflow real necesita.
2. **Prueba cada skill contigo mismo (cliente cero) antes de ofrecerlo.** Si nunca corriste `small-business:cash-flow-snapshot` con datos reales, no sabes si sirve para tu cliente.
3. Cuando actives uno de estos paquetes para un cliente y funcione bien, regístralo abajo — así construyes el mapa real de qué vertical usa qué.
